Core Architecture Blueprint

📦 Origin Storage (S3)

Hosts static assets in a private bucket locked down via Origin Access Control (OAC) to prevent unauthorized public access.

⚡ Edge Delivery (CloudFront)

Caches content across global edge locations to ensure ultra-low latency and secure HTTPS delivery for end-users.

🔒 Security & Routing

Managed via AWS Certificate Manager (ACM) for SSL/TLS certificates and Route 53 Alias records for seamless custom domain routing.
