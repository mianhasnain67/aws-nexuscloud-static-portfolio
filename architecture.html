How it works

Simple origin. Global reach.

A serverless delivery path brings static content from a protected storage origin to visitors through a global edge network.

A request, step by step

  1. 01 · Visitor A user opens your custom domain in a browser.
  2. 02 · Route 53 DNS routes the domain to the CloudFront distribution.
  3. 03 · CloudFront The edge network serves a cached response over HTTPS when available.
  4. 04 · Private S3 origin On a cache miss, CloudFront retrieves the requested asset from S3 using Origin Access Control.

Secure delivery

CloudFront provides the public delivery layer, while Origin Access Control lets the S3 bucket remain private to direct visitors.

Managed HTTPS

A certificate from AWS Certificate Manager can secure the custom domain at the CloudFront distribution.

Fewer moving parts

Static assets can be delivered without managing web servers, while caching helps reduce repeated origin requests.
